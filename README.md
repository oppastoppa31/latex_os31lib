# os31lib

This is a LaTeX package that provides a set of macros and environments for
making homework assignments easier to write and read. It includes features for
formatting mathematical expressions, creating problem sets, and generating
solutions.

## Installation

```bash
chmod +x install.sh
./install.sh
```

## Documentation

View the documentation by running:

```bash
pdflatex os31lib.dtx
open os31lib.pdf
```
